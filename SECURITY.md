# Segurança

A ROM pública não precisa conter credenciais de escrita no GitHub ou a chave privada de distribuição. O novo protocolo usa uma chave pública fixada no cliente e manifestos Ed25519, com integridade e identidade do pacote verificadas antes do preparo.

Não publique senhas, tokens, chaves privadas, códigos de suporte ou arquivos de contas em issues. Para um incidente com dados sensíveis, utilize o atendimento oficial do projeto e envie apenas os detalhes necessários. Nunca compartilhe a imagem completa de um cartão que já contém seus dados.

A primeira release espelhada tem o cliente R2 anterior; a release que incorporar o novo cliente identificará a assinatura automática e os dois provedores. Um repositório privado não será contornado com token nos aparelhos.

Este repositório não promete invulnerabilidade, secure boot ou atestação de hardware. A proteção dos serviços de conta e suporte tem suas próprias autorizações, independentemente de o arquivo da ROM ser público.
